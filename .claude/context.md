# Bối cảnh dự án

## Tên dự án

- `tnauto-admin`

## Mục tiêu

- Xây dựng trang quản trị cho hệ thống TNAUTO.
- Tập trung vào thao tác quản lý dữ liệu, giám sát và vận hành.

## Công nghệ chính

- Frontend: React + Vite
- Routing: React Router
- HTTP Client: Axios
- UI Icons: Heroicons / Lucide
- Styling: Tailwind CSS
- Backend/Auth/DB (nếu dùng): Firebase

## Đối tượng sử dụng

- Quản trị viên nội bộ hoặc nhân sự vận hành hệ thống.

## Ưu tiên sản phẩm

- Giao diện rõ ràng, thao tác nhanh.
- Dữ liệu chính xác, phản hồi lỗi minh bạch.
- Dễ bảo trì, dễ mở rộng tính năng.

## Ghi chú domain (cần cập nhật thêm)

> Team nên bổ sung thêm tại đây:
- Các module chính (ví dụ: người dùng, đơn hàng, sản phẩm, báo cáo...).
- Quy tắc nghiệp vụ quan trọng.
- Vai trò và phân quyền.
- Luồng xử lý quan trọng cần tránh phá vỡ.
